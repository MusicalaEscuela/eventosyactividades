# Setlist / Orden de presentación

La pestaña Setlist reutiliza las inscripciones y el catálogo de presentaciones. No crea otra inscripción ni otra duración. Los ensambles cuentan una vez y las obras compartidas no se repiten como solistas. Exposiciones y cancelados quedan fuera.

- Muestra confirmados y realizados; permite incluir pendientes para preparar el orden.
- Cada tarjeta tiene posición numérica y botones subir/bajar. Las canciones se ordenan dentro de cada presentación.
- El orden se guarda en el evento y se comparte entre dispositivos. La tabla de participantes respeta el orden de canciones y ofrece acceso al setlist.
- Durante el evento: Por llamar, Llamado, En escena, Terminado u Omitido. Las canciones pueden marcarse realizadas por separado. No completa automáticamente la trayectoria académica.
- En escena y Sigue se calculan con la vista actual. Se debe terminar o retirar la presentación en escena antes de marcar otra.
- Imprimir / guardar PDF crea un documento exclusivo del setlist con obras, docentes, apoyos y recursos. Respeta el filtro de confirmación elegido. No incluye los controles de edición.
- Los números mantienen el orden general aunque se oculten pendientes. Cambiar la vista no borra turnos ni reinicia marcas.
- Minuto a minuto mantiene las horas, transiciones y actividades generales. El setlist no las modifica.
- Un cambio concurrente se avisa para evitar sobrescribir el trabajo de otra persona.
